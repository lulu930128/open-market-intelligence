# Open Market Intelligence

Open Market Intelligence is a public-data-driven market intelligence system.

The project is designed to collect, normalize, and analyze public market data, company disclosures, financial news, and international events. Its goal is to generate traceable pre-market and post-market research reports.

## Core Principles

- Public data only
- Local-first architecture
- Raw data preservation
- Source traceability
- Rule-based analysis before AI summarization
- No automated trading
- No use of non-public material information

## Planned Modules

- Market data collectors
- Company event collectors
- News and RSS collectors
- International event collectors
- Source registry
- Rule engine
- Report generator
- Private dashboard
