後端資料來源與程式更新說明
日期：2026-05-21

一、更新目的
本次更新把原本偏向 TWSE/MOPS 的資料範圍補齊到 TPEx 上櫃市場。
新增後，後端可抓取並解析：
1. 上櫃日行情
2. 上櫃公司基本清單
3. 上櫃三大法人買賣超
4. 上櫃融資融券餘額

新聞資料仍未納入本次範圍。

二、新增資料來源
1. TPEx Mainboard Daily Quotes
   - source_id：6
   - parser_type：tpex_daily_quotes
   - 官方 API：
     https://www.tpex.org.tw/www/zh-tw/afterTrading/dailyQuotes
   - 用途：抓取上櫃每日收盤、開高低收、成交量、成交金額、成交筆數。

2. TPEx Domestic Company Profile
   - source_id：7
   - parser_type：tpex_company_profile
   - 官方 API：
     https://www.tpex.org.tw/www/zh-tw/company/otcSearch?type=stkType&stkType=%20&response=json
   - 用途：抓取本國上櫃公司清單與產業別。

3. TPEx Foreign Company Profile
   - source_id：8
   - parser_type：tpex_company_profile
   - 官方 API：
     https://www.tpex.org.tw/www/zh-tw/company/otcSearch?type=stkType&stkType=RR&response=json
   - 用途：抓取外國上櫃公司清單與產業別。

4. TPEx Institutional Trading
   - source_id：9
   - source_type：api_bundle
   - parser_type：tpex_institutional_trade
   - 官方 API 組合：
     - 外資買超：insti/qfiiStat?searchType=buy
     - 外資賣超：insti/qfiiStat?searchType=sell
     - 投信買超：insti/sitcStat?searchType=buy
     - 投信賣超：insti/sitcStat?searchType=sell
     - 自營商買超：insti/dealerStat?stype=buy
     - 自營商賣超：insti/dealerStat?stype=sell
   - 用途：把 TPEx 拆開的法人表合併成 institutional_trade_daily。
   - 單位處理：官方法人欄位為張數，parser 會乘以 1000，轉成與 TWSE 法人資料一致的股數。
   - 注意：TPEx 自營商 API 的買進與賣出欄位是金額，不是張數，所以本次只寫入自營商買賣超張數，不把金額塞進買進股數或賣出股數欄位。

5. TPEx Margin Trading Balance
   - source_id：10
   - parser_type：tpex_margin_trading
   - 官方 API：
     https://www.tpex.org.tw/www/zh-tw/margin/balance
   - 用途：抓取上櫃融資買進、賣出、現償、餘額，以及融券賣出、買進、償還、餘額與資券相抵。

三、新增與修改的程式碼
1. backend/app/connectors/http_bundle_connector.py
   - 新增多 API 合併抓取 connector。
   - endpoint_url 可存 JSON object，key 是子資料名稱，value 是實際 API URL。
   - 抓完後會把每個子 API 的 status_code、content_type、raw_text 合併存成一份 raw_text。
   - 這是為了處理 TPEx 三大法人資料被拆成外資、投信、自營商，且買超與賣超又分開查詢的情況。

2. backend/app/connectors/factory.py
   - 新增 source_type：api_bundle / http_bundle。
   - 這兩種 source_type 會交給 HttpBundleConnector 處理。

3. backend/app/pipelines/fetch_pipeline.py
   - 新增日期 placeholder：
     {latest_market_trade_date_roc_yyy_mm_dd}
   - 會把最新 market_daily_price 交易日轉成民國年格式，例如 2026-05-12 轉成 115/05/12。
   - TPEx 部分官方 API 需要這種民國年斜線日期格式，不能直接使用 20260512。

4. backend/app/parsers/twse_common.py
   - 新增 parse_float。
   - 讓 TPEx 日行情 parser 可以共用數字清理邏輯，處理逗號、正負號、空值。

5. backend/app/parsers/tpex_daily_quotes.py
   - 新增 TPEx 上櫃日行情 parser。
   - 寫入 market_daily_price。
   - 對應欄位包含 stock_id、stock_name、open_price、high_price、low_price、close_price、price_change、trade_volume、trade_value、transaction_count。

6. backend/app/parsers/tpex_company_profile.py
   - 新增 TPEx 上櫃公司清單 parser。
   - 寫入 stock_profile。
   - 同步更新 stock_master，market 會標記為 TPEX。

7. backend/app/parsers/tpex_institutional_trade.py
   - 新增 TPEx 法人買賣超 parser。
   - 讀取 api_bundle 內的六份官方 payload。
   - 以 stock_id 合併外資、投信、自營商資料。
   - 寫入 institutional_trade_daily。
   - total_institutional_net = foreign_investor_net + investment_trust_net + dealer_net。

8. backend/app/parsers/tpex_margin_trading.py
   - 新增 TPEx 融資融券 parser。
   - 寫入 margin_trading_daily。
   - 對應融資餘額、融券餘額、資券相抵與備註欄位。

9. backend/app/pipelines/parse_pipeline.py
   - 註冊新增 parser_type：
     - tpex_daily_quotes
     - tpex_company_profile
     - tpex_institutional_trade
     - tpex_margin_trading
   - 新增四個 parse raw result 入口。
   - 每次 parse 都會先清掉同 source_id、同 trade_date 或同 stock_id 的舊資料，再寫入新資料。

10. backend/app/scripts/seed_sources.py
    - 新增五個 TPEx 官方來源。
    - 後續重跑 seed_sources 時可以自動建立或更新 TPEx source registry。

11. backend/app/quality/checker.py
    - 新增 TPEx table payload 檢查。
    - 新增 TPEx institutional bundle 檢查。
    - 可檢查 JSON 格式、stat 是否 ok、是否有 tables/data、各子 API row_count。
